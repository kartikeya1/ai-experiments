# Roadmap & Pending Work — ai-experiments

What this repo is: AI-assisted product experiments, served as one Vercel site with no build step.
`voyage-evolution/` is a nested mini-showcase — a case-study page with a live iframe, plus `v1/`
(Aurora Voyage: Leaflet + OpenStreetMap, `app.js` at 2,275 lines) and `v2/` (Voyagr: a single
self-contained `index.html` at 2,176 lines). `sign-bridge/` translates text to ASL/ISL hand shapes
from a generated dictionary. The home page also carries an external card for ResumeForge.

Phases are meant to be executed in order — P0 → P5. Within a phase, items are independent.
The numbering is shared across all of Kartikeya's repos: **P0** stop the bleeding · **P1** tests/CI ·
**P2** truth in docs · **P3** polish · **P4** features · **P5** decision-gated.

## Phase 3 — Polish

- [ ] **Crawlers see the word "Showcase".** `index.html` ships `<title>Showcase</title>` with an empty `<meta name="description">`; `assets/home.js` rewrites both at runtime. **The three `index.html` files in this repo, pm-utilities and pm-showcase are md5-identical — one fix, three repos.**
- [ ] No Open Graph / Twitter cards, no `apple-touch-icon`, no `robots.txt`, no `sitemap.xml`.
- [ ] **Asset size** — `voyage-evolution/v2/index.html` is 2,176 lines with all CSS and JS inlined and unminified, the largest deployed asset across the three static sites; `v1/app.js` is 2,275 lines. No build step means no minification. Fine for a portfolio; worth knowing before adding a fourth experiment.
- [ ] `v1` loads Leaflet + OpenStreetMap tiles from a CDN, so it breaks offline and depends on a third party staying up. No SRI on the script tag.
- [ ] Accessibility: `sign-bridge` renders generated hand shapes with no text alternative for the shape sequence, and the Voyage apps have no keyboard path through the itinerary editor.
- [x] **Security header present** — `vercel.json` sets `X-Content-Type-Options: nosniff` site-wide. This is the **only** security header in any of the three static-site repos; worth copying to the other two rather than changing here.
